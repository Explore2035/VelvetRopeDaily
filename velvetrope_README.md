## Setup

1. Create a new GitHub repo called `VelvetRopeDaily`
2. Upload files:
   - `pipeline.py` → root
   - `README.md` → root
   - `deploy.yml` → `.github/workflows/deploy.yml`
3. Add secret: `ANTHROPIC_API_KEY`
4. Enable GitHub Pages (Settings → Pages → main / root)
5. Run workflow manually first time
